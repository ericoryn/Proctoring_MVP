# Проверка сборки — 8 октября 2026

## Выполнено

- 47 автоматических тестов прошли в `.venv`, включая два теста скрытого Tk-окна.
  GUI-тесты включались через `PROCTORING_GUI_TEST=1`; камера и реальные хуки не использовались.
- Консольный `--self-test`: RUNNING → PAUSED → PAUSED → RUNNING → STOPPED;
  повторное чтение SQLite подтвердило сохранённый ответ и отправленный результат.
- Проверены импорт OpenCV, MediaPipe, PyTorch и Win32; `pip check` не выявил
  несовместимых требований. Снимок — `requirements-validated.txt`.
- Независимое ревью выявило ошибки, которые исправлены и покрыты регрессионными
  тестами: преждевременный STOPPED при отказе диска, остановка UI-проверок при
  исключениях, потеря/дублирование технических событий, непарные события клавиш.
- Таймеры приведены к единой монотонной базе `perf_counter` (QueryPerformanceCounter).
  У установленного Python 3.10 `monotonic` использует GetTickCount64 с шагом 15.625 мс;
  для коротких этапов профиля выбран более точный монотонный источник.

## Реальные модели, искусственные кадры

Последний прогон `python -m proctoring.profile --synthetic --seconds 5 ...` завершился
с кодом 0: 138 обработанных кадров, ошибок нет, оставшихся рабочих потоков нет.
Источник — чёрное изображение 640×480, CPU, без камеры. Последнее наблюдение:
`face_absent`, faces=0. Исходный JSON: `data/profile-synthetic.json`.

| Метрика | p95 | Максимум |
|---|---:|---:|
| YOLO | 37.01 мс | 1192.12 мс |
| MediaPipe | 3.50 мс | 3.63 мс |
| Полный анализ | 39.68 мс | 1195.22 мс |
| Возраст результата | 69.89 мс | 1203.03 мс |

Загрузка до первого результата заняла 3.42 с. Максимум включает первый анализ.
Это проверка совместимости API и измерений. Не использовать эти числа как калибровку
экзамена: чёрный кадр не содержит лиц и телефонов.

Дополнительно адаптер обработал штатное фото из пакета Ultralytics и его правую
половину. На полном фото — faces=0, на фрагменте — faces=1, gaze=right, head=center;
ветка blendshapes/матрицы головы выполнилась без исключения. Это smoke-проверка
интеграции, не измерение качества детекции.

При первом предварительном прогоне один поток не завершился в пределах 1 с;
это отразилось в `workers_alive_at_exit`, код выхода был 1. Диагностический и два
последующих прогона завершились без оставшихся потоков. Гарантия ограниченного
ожидания сохраняется; универсальная гарантия завершения нативных библиотек не заявляется.
