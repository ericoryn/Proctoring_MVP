## 🎯 About

MVP для кейса «Локальный прокторинг — защита браузера, контроль взгляда и детекция смартфонов» на **Qostanai Industry Hackathon**, предложенного Костанайским региональным университетом совместно с **Qostanai Hub**.

Система помогает замечать телефон, отсутствие участника, второе лицо и длительный отвод взгляда во время тестирования. Анализ выполняется локально; наблюдения сохраняются для последующей проверки человеком.

**Технический сбой не должен приводить к потере ответов.** При отказе контроля тест приостанавливается и продолжается только после восстановления необходимых проверок.

## ✨ Features

- 📱 **Детекция смартфона:** распознавание класса `cell phone` и журнал эпизодов появления.
- 👀 **Контроль внимания:** эвристики длительного отвода взгляда и поворота головы.
- 👥 **Контроль присутствия:** обнаружение отсутствия лица и появления второго лица.
- 🪟 **Защита окружения Windows:** контроль фокуса; опциональная блокировка Alt+Tab, Ctrl+C/V, Win, PrtScn и основных сочетаний вкладок в целевом окне.
- ⏸️ **Отказоустойчивость:** `RUNNING / PAUSED / STOPPED`, пауза при сбое камеры или устаревании анализа.
- 💾 **Сохранение ответов:** SQLite, восстановление прерванной сессии, запрет изменения и отправки ответов во время паузы.
- 🧾 **Раздельный журнал:** технические ошибки, наблюдаемые нарушения и события сессии.
- ⚡ **Обработка последнего кадра:** отсутствие накопления очереди изображений внутри приложения.
- 🧪 **Демо без камеры** и отдельный профилировщик реальных моделей.

## 🧰 Стек технологий

| Компонент | Назначение |
|---|---|
| Python 3.10+, threading | Приложение и рабочие потоки |
| Ultralytics YOLO11n | Проверенная модель детекции телефона |
| YOLOv8n | Альтернативные веса через `--yolo-model`; требуют отдельной проверки |
| MediaPipe Face Landmarker | Сетка лица (Face Mesh), коэффициенты выражений и положение головы |
| OpenCV | Получение и преобразование кадров |
| pywin32, keyboard | Контроль фокуса и клавиатурные хуки |
| Tkinter | Локальное окно тестирования |
| SQLite, unittest | Хранение данных и автоматические тесты |

Текущая сборка проверена с **YOLO11n** и **MediaPipe Tasks Face Landmarker**; старый интерфейс `mp.solutions.face_mesh` не используется.

## 🚀 Quick Start

**Среда:** Windows 11, Git Bash, 64-битный Python с Tkinter. Проверенная конфигурация — Python 3.10. Команды ниже выполняются в **Git Bash**, не в PowerShell.

### 1. Клонирование и установка

Замените `YOUR_USERNAME` на владельца репозитория.

```bash
git clone https://github.com/YOUR_USERNAME/local-proctoring-mvp.git
cd local-proctoring-mvp

python -m venv .venv
source .venv/Scripts/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

`requirements.txt` устанавливает проект с CV- и Windows-зависимостями, используя версии из `requirements-validated.txt`.

### 2. Запуск демо

```bash
python -m proctoring --demo
```

Переключатели моделируют сбой камеры, зависание CV, потерю фокуса и телефон. Камера и системные хуки не включаются. Само демо можно запустить и без CV-зависимостей — достаточно Python с Tkinter.

Проверка сохранения и восстановления без интерфейса:

```bash
python -m proctoring --self-test
```

### 3. Загрузка моделей

Веса исключены из Git. Загрузите их из официальных источников до реального запуска:

```bash
mkdir -p models

curl --fail --location --retry 3 \
  https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11n.pt \
  --output models/yolo11n.pt

curl --fail --location --retry 3 \
  https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task \
  --output models/face_landmarker.task
```

### 4. Замеры и реальная камера

Эта команда включает камеру и сохраняет профиль:

```bash
python -m proctoring.profile \
  --camera 0 --seconds 60 \
  --yolo-model models/yolo11n.pt \
  --face-model models/face_landmarker.task \
  --output data/profile-camera.json
```

Выберите таймауты по замерам и допустимому интервалу отсутствия контроля. Значения — в секундах, дробная часть через точку.

```bash
read -r -p "Допустимый возраст кадра, с: " FRAME_AGE
read -r -p "Интервал без анализа, с: " ANALYSIS_TIMEOUT
read -r -p "Таймаут камеры и фокуса, с: " MONITOR_TIMEOUT

python -m proctoring \
  --yolo-model models/yolo11n.pt \
  --face-model models/face_landmarker.task \
  --max-frame-age "${FRAME_AGE:?Введите значение}" \
  --analysis-timeout "${ANALYSIS_TIMEOUT:?Введите значение}" \
  --monitor-timeout "${MONITOR_TIMEOUT:?Введите значение}" \
  --lock-keys
```

`--lock-keys` включает ограничения клавиш в целевом окне. **Выход: Ctrl+Shift+F12 или закрытие окна.** Без флага контроль фокуса и приостановка продолжают работать.

## 🏗️ Architecture

```text
Камера → поток захвата → буфер последнего кадра → CV-поток
                                                 YOLO + MediaPipe
                                                        │
Win32 / клавиатура → независимый system_lock.py          │
                              │                         │
                              └──────→ контроллер ←─────┘
                                       │
                              RUNNING / PAUSED / STOPPED
                                       │
                              Tkinter + SQLite + журнал
```

- **Захват** перезаписывает единственный доступный кадр.
- **CV-поток** выполняет модели вне блокировки буфера. Второй обработчик поверх зависшего не запускается.
- **Системный поток** наблюдает за фокусом и обслуживает хуки независимо от моделей.
- **Контроллер** проверяет `frame_id`, время получения кадра и завершения анализа по единой монотонной базе `perf_counter()`.
- **Основной поток** обслуживает интерфейс, сохранение и переходы состояний. Изменение и отправка ответов повторно проверяют состояние сессии.

При отказе: **PAUSED → ответы сохранены → все проверки восстановлены и получен свежий анализ → RUNNING**.

Буфер устраняет накопление кадров внутри приложения, но не сокращает длительность анализа. Поэтому профилировщик измеряет среднее, p95 и максимальные задержки.

## 📁 Данные и границы MVP

Ответы и журнал хранятся в `data/`: SQLite, `report.json`, `metrics.json`. Для восстановления прерванной сессии передайте её каталог через `--data-dir`. Видео и изображения лиц не сохраняются; данные сессий исключены из Git.

Прототип управляет **собственным окном тестирования**. Внешняя вкладка браузера или LMS пока не подключена. Ограничения клавиш и контроль фокуса не заменяют системный kiosk-режим.

Взгляд оценивается эвристически; наличие телефона не доказывает съёмку экрана. События требуют проверки человеком. Камера, точность детекции и физические горячие клавиши требуют ручного прогона на целевом компьютере.
